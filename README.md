# Ritresh Kumar — AI Product Portfolio

A responsive, static multi-page portfolio for GitHub Pages.

## Pages
- `index.html` — homepage and featured projects
- `projects.html` — project directory
- `asai-case-study.html` — detailed ASAI GEO case study
- `zepto-case-study.html` — proposed Zepto My Buckets PRD overview
- `parloa-case-study.html` — Parloa Voice AI research case study
- `about.html` — background, skills and contact

## Preview locally
Download/extract the folder and open `index.html` in a browser. All pages use local CSS and JavaScript; no build tools are required.

## Publish with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io` after GitHub finishes publishing.

Review your personal details and project claims before publishing. The ASAI case study intentionally excludes confidential query sets, competitor-by-competitor analysis, assessment matrix and scoring logic. The Zepto concept is labelled as proposed and not launched. The Parloa page is described as research, not direct product ownership.
